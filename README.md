# Terranova Residencial — RU GRUP

Sitio web comercial de Terranova Residencial, proyecto inmobiliario de RU GRUP en Huancayo.

## Desarrollo local

Requiere Node.js 22.13 o superior.

```bash
npm install
npm run dev
```

## Publicación

La versión para GitHub Pages se genera en `out/` mediante:

```bash
npm run build:pages
```

El despliegue se ejecuta automáticamente desde la rama `main` y utiliza el dominio `terranova.ru-grup.uk`.
